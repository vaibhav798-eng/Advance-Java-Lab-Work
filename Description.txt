College Management System in Java using JDBC
This is a simple College Management System using Java, JDBC, and MySQL. It is suitable for a college project or Java practical assignment. The program allows you to add, view, search, update, and delete student records stored in a MySQL database.

1. Project description
Project name: College Management System

Technology used:
- Java: Implements the application logic.
- JDBC (Java Database Connectivity): Connects Java to the database.
- MySQL: Stores student information.
- PreparedStatement: Executes SQL queries safely using parameters.

Main features
1. Add a new student.
2. Display all students.
3. Search for a student using their ID.
4. Update student details.
5. Delete a student record.
6. Exit the application.

4. How the program works
The application follows this process:

Program execution flow
1. The program loads the MySQL JDBC driver.
2. A menu appears on the console.
3. The user selects an operation.
4. Java connects to the MySQL database.
5. JDBC executes the required SQL query.
6. The result or success message is displayed.
7. The program returns to the menu until the user chooses Exit.

Explanation of important JDBC methods

Method or class	                                        Purpose
DriverManager.getConnection()	Establishes a connection with MySQL.
Connection	                                        Represents the database connection.
Statement	                                                            Executes a basic SQL query.
PreparedStatement	                                        Executes parameterized SQL queries.
executeQuery()	                                        Executes a SELECT query and returns a ResultSet.
executeUpdate()	                                        Executes INSERT, UPDATE, or DELETE queries.
ResultSet	                                                            Reads records returned by a query.
close()	                                                            Releases resources; try-with-resources closes JDBC objects automatically.

5. Advantages of the project

- Reduces manual record-keeping.
- Stores student records permanently in a database.
- Makes searching and updating records easier.
- Demonstrates Java database connectivity and CRUD operations.
- Uses parameterized SQL queries to reduce SQL injection risks.
